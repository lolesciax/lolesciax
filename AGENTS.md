# Repository workflow

- Work directly on `main`. Do not create branches or worktrees unless the user explicitly requests them.
- After completing and verifying each task or meaningful milestone, commit the task's changes and automatically push `main` to `origin` without asking for confirmation.
- Include only changes relevant to the completed task in each commit.
- If a push is rejected, inspect the remote changes and integrate them while preserving the user's work. Never force-push unless explicitly authorized.
