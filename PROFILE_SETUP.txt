GITHUB PROFILE SETUP — @lolesciax
=================================

These are ready-to-upload profile README files. No existing repository was modified.

1. At https://github.com/new create a PUBLIC repository named exactly:
   lolesciax

   GitHub only displays a profile README if the public repository name
   exactly matches the account name and contains README.md at its root.

2. Clone that newly created repository onto your computer.

3. Extract this ZIP directly into the cloned repository root. Keep:
   README.md
   assets/hero-light.svg
   assets/hero-dark.svg

4. From the cloned repository directory, run:
   git add README.md assets/hero-light.svg assets/hero-dark.svg
   git commit -m "docs: add developer profile README"
   git push origin main

   If you initialized the new repository with README.md, replace that existing
   file with the provided README.md before running git add.

5. Open https://github.com/lolesciax to verify the README and its
   light/dark themed banner appear on your main profile page.
